Introduction to Node.js

Before writing any Node.js code you need to install the runtime and understand how to run JavaScript outside the browser.

What is Node.js?

Node.js is an open-source, cross-platform JavaScript runtime built on Google Chrome's V8 engine. It lets you execute JavaScript on the server — outside a browser — and is particularly suited for:

  • Building web servers and REST APIs
  • Real-time applications (chat, gaming, live dashboards)
  • Command-line tools and automation scripts
  • Streaming data pipelines

Node.js uses a single-threaded, event-driven, non-blocking I/O model. This allows it to handle thousands of concurrent connections efficiently without the overhead of spawning a new OS thread per request.

Installing Node.js

Always install the LTS (Long Term Support) version — it is the most stable and receives security patches for 30 months. Download it from nodejs.org. 

# Option 1 – Download the Windows Installer (.msi) from https://nodejs.org
# Option 2 – Install via winget (Windows 10/11)
winget install OpenJS.NodeJS.LTS

# Option 3 – Install via Chocolatey
choco install nodejs-lts

After installation, open PowerShell or Command Prompt and verify (see below).

# Option 1 – Download the macOS pkg from https://nodejs.org
# Option 2 – Homebrew (recommended)
brew install node

# Option 3 – MacPorts
sudo port install nodejs22 +lts

After installation, open Terminal and verify (see below).

# Official NodeSource repository (recommended for Debian/Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Fedora / RHEL / CentOS
sudo dnf module install nodejs:lts/default

# Arch Linux
sudo pacman -S nodejs npm

nvm (Node Version Manager) lets you switch between multiple Node.js versions on the same machine — ideal for developers.

# macOS / Linux — install nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc  # or ~/.zshrc on macOS

# Install and use the LTS version
nvm install --lts
nvm use --lts
nvm alias default node  # make it the default

# Windows — use nvm-windows
# Download installer from https://github.com/coreybutler/nvm-windows/releases
nvm install lts
nvm use lts

Verify the Installation

After installation, open a terminal (PowerShell / Command Prompt / Terminal / bash) and run:

node --version
npm --version

You should see output similar to:

v22.11.0
10.9.0

If the node command is not found, restart your terminal or machine so the PATH changes take effect.

Running a .js File

Node.js executes JavaScript files directly from the terminal. No compilation step is required — unlike C or Java.

# Navigate to the folder containing your file
cd C:\Users\YourName\projects\hello

# Run the file
node hello.js
# Navigate to the folder containing your file
cd ~/projects/hello

# Run the file
node hello.js

# Alternatively, make it executable (Linux/macOS)
chmod +x hello.js
./hello.js  # requires #!/usr/bin/env node as first line

Key point: node <filename> works identically on all operating systems. There is no compile step.

Using the Node.js REPL

The REPL (Read-Eval-Print Loop) is an interactive shell. Start it by typing node with no arguments:

$ node
Welcome to Node.js v22.11.0.
Type ".help" for more information.
> 2 + 2
4
> console.log("Hello, Node!")
Hello, Node!
undefined
> .exit

The REPL is perfect for quick experiments. Press Ctrl+C twice or type .exit to quit.

Your First Node.js Script

Create a file called hello.js with the following content:

// hello.js
const message = "Hello from Node.js!";
console.log(message);

const os = require("os");
console.log(`Running on: ${os.platform()} (${os.arch()})`);
console.log(`Node.js version: ${process.version}`);

Run it:

node hello.js

Expected output (varies by machine):

Hello from Node.js!
Running on: darwin (arm64)
Node.js version: v22.11.0

That's it — you have a working Node.js environment. Move on to Chapter 1 to dive deeper.
