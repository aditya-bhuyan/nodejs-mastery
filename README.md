## 📚 Contents

- **Intro** — Installing Node.js and running `.js` files on Windows, macOS, and Linux
- **Chapter 1** — Foundations of Node.js
- **Chapter 2** — Modules, npm & the CommonJS System
- **Chapter 3** — Asynchronous JavaScript & the Event Loop
- *(more chapters coming)*

## 🗂 Structure

Each chapter contains:

| Folder | Description |
|--------|-------------|
| `learning/` | Concept explanations and theory |
| `examples/` | Annotated runnable code examples |
| `quiz/` | Multiple-choice quizzes |
| `exercises/` | Coding challenges for the learner |
| `solutions/` | Reference solutions |

## 🚀 Running locally

This is a static HTML site — no build step required.

```bash
# Clone the repo
git clone https://github.com/aditya-bhuyan/nodejs-mastery.git
cd nodejs-mastery

# Open in browser
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

Or deploy to Netlify by connecting the repo — `netlify.toml` is already configured.
