Chapter 2 — Modules, npm & CommonJS Beginner

2.1 Why Modules?

As programs grow, keeping all code in one file becomes unmanageable. Modules solve this by splitting code into separate files, each with its own scope. Variables defined in one module are not globally visible — you must explicitly export and import them.

Node.js supports two module systems:

  • CommonJS (CJS) — require() / module.exports — the original Node.js system, still the default for .js files unless "type":"module" is in package.json.
  • ES Modules (ESM) — import / export — the standard introduced with ES2015 (ES6); supported natively in Node.js 12+.

This chapter focuses on CommonJS, which you will encounter in most existing Node.js codebases.

2.2 CommonJS: require() and module.exports

require() loads a module and returns whatever that module exported. Modules are cached after the first load — subsequent require() calls return the same object.

// math.js  — exporting multiple values
function add(a, b) { return a + b; }
function sub(a, b) { return a - b; }
const PI = 3.14159;

module.exports = { add, sub, PI };
// app.js  — importing
const math = require("./math");   // "./" = relative path

console.log(math.add(3, 4));  // 7
console.log(math.PI);         // 3.14159

// Destructuring is common
const { add, PI } = require("./math");
console.log(add(1, 2));  // 3

2.3 Exporting a Single Value / Class

// logger.js
class Logger {
  log(msg)   { console.log(`[INFO]  ${msg}`); }
  error(msg) { console.error(`[ERROR] ${msg}`); }
}

module.exports = Logger;  // export the class itself
// app.js
const Logger = require("./logger");
const log = new Logger();
log.log("Server started");   // [INFO]  Server started

2.5 npm and package.json

npm (Node Package Manager) is bundled with Node.js. It lets you install, publish, and manage third-party packages from npmjs.com. 

# Initialise a new project (creates package.json)
npm init -y

# Install a package and save it as a dependency
npm install express

# Install a dev-only dependency (not needed in production)
npm install --save-dev nodemon

# Install all dependencies listed in package.json
npm install

# Remove a package
npm uninstall express

2.6 package.json Explained

{
  "name": "my-app",
  "version": "1.0.0",
  "description": "A simple Node.js app",
  "main": "index.js",         // entry point
  "scripts": {
    "start": "node index.js",
    "dev": "nodemon index.js"  // run with: npm run dev
  },
  "dependencies": {
    "express": "^4.21.2"      // ^ = compatible with 4.x.x
  },
  "devDependencies": {
    "nodemon": "^3.1.9"
  },
  "license": "GPL-3.0"
}

2.7 ES Modules (ESM) — Quick Overview

Set "type": "module" in package.json to use import / export:

// math.mjs  (or .js with "type":"module")
export const add = (a, b) => a + b;
export default function multiply(a, b) { return a * b; }

// app.mjs
import multiply, { add } from "./math.mjs";
console.log(add(2, 3));       // 5
console.log(multiply(4, 5));  // 20
