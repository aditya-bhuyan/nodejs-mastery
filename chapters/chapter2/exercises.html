Chapter 2 — Coding Exercises

Exercise 1 — String Utilities Module

Create a file stringUtils.js that exports the following functions:

  • capitalize(str) — capitalizes the first letter
  • reverseWords(str) — reverses the word order in a sentence
  • countWords(str) — returns the number of words
  • isPalindrome(str) — returns true if the string reads the same forwards and backwards (ignore case, spaces)

Then create testStrings.js that requires the module and tests each function with at least two inputs.

Exercise 2 — File Info Tool

Create fileinfo.js that accepts a file path as a command-line argument and prints:

  • File name (without directory)
  • File extension
  • Parent directory (absolute)
  • Whether the file exists (use fs.existsSync)

Use the path and fs built-in modules.

node fileinfo.js ./package.json

Exercise 3 — Simple Calculator Module

Create calc.js that exports an object with four methods: add, subtract, multiply, divide. divide should throw an Error with the message "Division by zero" if the divisor is 0.

Create runCalc.js that imports the calculator, calls all four operations with example values, wraps divide in a try/catch, and logs every result.

Exercise 4 — System Report Script

Create sysreport.js that uses the os module to print a formatted system report like: 

=== System Report ===
Hostname  : macbook-pro.local
Platform  : darwin
Arch      : arm64
CPUs      : 10
Total RAM : 16.00 GB
Free RAM  : 4.32 GB
Uptime    : 3h 22m

Format uptime as hours and minutes (use os.uptime() which returns seconds).
