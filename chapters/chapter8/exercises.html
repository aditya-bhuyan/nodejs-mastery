Chapter 8 — Coding Exercises

Try each exercise before looking at the solutions.

Exercise 1 — Secure Register/Login API

Build a complete auth API with Express:
  • POST /register — validate email + password (min 8 chars), hash with bcrypt, store user
  • POST /login — verify credentials, return a JWT that expires in 1 hour
  • GET /me — protected; return the authenticated user's email and id
Load the JWT secret from process.env.JWT_SECRET and throw a startup error if it's missing.

Exercise 2 — Joi Validation Middleware

Create a reusable validate(schema) middleware factory using joi. Apply it to a POST /products route that requires { name: string (2-100 chars), price: positive number, category: string }. Return descriptive 400 errors on invalid input.
