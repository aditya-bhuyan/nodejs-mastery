Chapter 5 — Coding Exercises

Try each exercise before looking at the solutions.

Exercise 1 — Query-Filtered List API

Create todos-api.js with an in-memory array of 10 todo objects ({ id, title, done }). Implement:
  • GET /todos — return all todos; support ?done=true/false filter
  • GET /todos/:id — return one todo or 404
  • PATCH /todos/:id — toggle done field, return updated object

Exercise 2 — Request Logger Middleware

Create logger-server.js that wraps any handler function with a logging layer that prints to stdout: 
[2024-01-01T10:00:00.000Z] GET /users → 200 (4ms)
Measure actual response time using Date.now() or process.hrtime().

Exercise 3 — Static File Server

Create static-server.js that serves files from a ./public directory. It should:
  • Detect the content type from the file extension (html, css, js, json, png, jpg)
  • Return 404 if the file doesn't exist
  • Default to index.html when the path is /
