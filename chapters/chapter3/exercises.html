Chapter 3 — Coding Exercises

Exercise 1 — Promise-based Delay Utility

Create delay.js that exports a delay(ms) function returning a Promise that resolves after ms milliseconds.

Then write a main.js that uses async/await to:

  1. Print "Step 1"
  2. Wait 1 second
  3. Print "Step 2"
  4. Wait 500 ms
  5. Print "Step 3 — done"

Exercise 2 — Async File Copier

Create copyfile.js that accepts source and destination as command-line arguments and copies the source file to the destination using fs/promises and async/await.

Requirements:

  • If the source file does not exist, print a clear error and exit with code 1.
  • On success, print: Copied <src> → <dest>
node copyfile.js README.md README.backup.md

Exercise 3 — Parallel vs Sequential Timing

Create timing.js. Using your delay utility (or inline), demonstrate the difference in total time between:

  1. Sequential: await delay(1000) then await delay(1000) — should take ~2 s
  2. Parallel: await Promise.all([delay(1000), delay(1000)]) — should take ~1 s

Print the elapsed time (in ms) for each approach using Date.now() or performance.now().

Exercise 4 — Event Emitter Logger

Create logger.js that exports a Logger class extending EventEmitter with three methods:

  • info(msg) — emits an "log" event with { level: "INFO", msg }
  • warn(msg) — emits a "log" event with { level: "WARN", msg }
  • error(msg) — emits an "error" event with { level: "ERROR", msg }

In app.js, instantiate the logger, register a listener for "log" that prints [LEVEL] message, register a listener for "error" that prints to stderr, then call each method once.
