Chapter 6 — Coding Exercises

Try each exercise before looking at the solutions.

Exercise 1 — Todo REST API with Express

Build a full CRUD REST API for todos using Express Router. Todos: { id, title, done, createdAt }.
  • GET /todos — list all, with optional ?done= filter
  • POST /todos — create new
  • PUT /todos/:id — replace
  • PATCH /todos/:id — update done only
  • DELETE /todos/:id — remove
Wrap all route handlers in asyncHandler and add a global error middleware.

Exercise 2 — Rate Limiter Middleware

Write a rateLimiter(limit, windowMs) middleware factory that allows at most limit requests per IP per windowMs milliseconds, returning HTTP 429 with { error: "Too Many Requests" } when exceeded. Use a plain JS Map for storage.

Exercise 3 — JSON Body Validator

Write a middleware factory validate(schema) where schema is an object like { name: 'string', age: 'number' }. It should reject requests with 400 if any required field is missing or has the wrong type. Apply it to a POST /users route.
