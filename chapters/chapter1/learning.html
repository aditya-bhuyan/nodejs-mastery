Chapter 1 — Foundations of Node.js Beginner

1.1 The V8 Engine

Node.js is powered by V8, the same JavaScript engine used in Google Chrome. V8 compiles JavaScript directly to native machine code using Just-In-Time (JIT) compilation, which is why Node.js is extremely fast for a scripting runtime.

V8 manages:

  • Memory allocation — via the heap
  • Garbage collection — automatic cleanup of unused objects
  • JIT compilation — converts JS to optimised machine code at runtime

1.2 The Node.js Architecture

Node.js adds several layers on top of V8:

  • libuv — cross-platform I/O library providing the event loop, thread pool, and async I/O
  • Node.js Core APIs — built-in modules like fs, http, os, path
  • npm — the world's largest package registry

1.3 Global Objects

In Node.js these objects are available everywhere without require():

  • global — the global namespace (equivalent of window in browsers)
  • process — information about the current Node.js process (process.env, process.argv, process.exit())
  • __dirname — absolute path of the directory containing the current file
  • __filename — absolute path of the current file
  • console — standard output/error logging
  • setTimeout, setInterval, clearTimeout, clearInterval

1.4 process Object in Depth

The process object is one of the most important globals:

// Print environment variable
console.log(process.env.PATH);

// Command-line arguments (index 0 = node, 1 = script path, 2+ = user args)
console.log(process.argv);

// Current working directory
console.log(process.cwd());

// Node.js and V8 version info
console.log(process.version);      // e.g. v22.11.0
console.log(process.versions.v8);  // e.g. 13.2.162.19

// Exit the process with a status code (0 = success, non-zero = error)
process.exit(0);

1.5 Writing to stdout and stderr

console.log("Standard output — informational messages");
console.error("Standard error — warnings and errors");
console.warn("Also goes to stderr");

// Structured logging with objects
console.log({ name: "Alice", role: "admin" });
console.table([{ name: "Alice" }, { name: "Bob" }]);

1.6 Node.js vs Browser JavaScript

Feature Browser JS Node.js
Global object window global
DOM / BOM ✅ Available ❌ Not available
File system access ❌ Sandboxed ✅ Full access via fs
Module system ES Modules (import) CommonJS + ES Modules
Networking Fetch API only http, https, net, dgram
