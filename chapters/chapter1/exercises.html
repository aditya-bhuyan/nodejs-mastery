Chapter 1 — Coding Exercises

Complete each exercise in a new .js file and run it with node <filename>.js. Solutions are in the next tab.

Exercise 1 — System Info Reporter

Create a file sysinfo.js that prints the following information to the console, each on its own labeled line:

  • Node.js version
  • Operating system platform
  • CPU architecture
  • Current working directory
  • The absolute path of the script itself

Hint: All of these are available on the process object or as globals.

Exercise 2 — Greeting with Command-Line Arguments

Create greet.js. When run as node greet.js Alice 30, it should print: 

Hello, Alice! You are 30 years old.
In 5 years you will be 35.

If fewer than 2 arguments are provided, print a usage message and exit with code 1: 

Usage: node greet.js <name> <age>

Hint: Use process.argv.slice(2) and process.exit(1).

Exercise 3 — Countdown Timer

Create countdown.js. It should:

  1. Accept a number N as a command-line argument (default 5 if not provided).
  2. Print the countdown from N down to 1, one number per second.
  3. After the countdown completes, print "Go!".

Example output for node countdown.js 3:

3
2
1
Go!

Hint: Use setInterval and clearInterval.

Exercise 4 — Minimal HTTP Server

Create server.js using the built-in http module that:

  1. Listens on 127.0.0.1:3000 (or PORT env var if set).
  2. Responds to any GET request with HTTP 200 and the body: Node.js is running!
  3. Responds to any other method with HTTP 405 and the body: Method Not Allowed
  4. Logs each request: method and URL.
