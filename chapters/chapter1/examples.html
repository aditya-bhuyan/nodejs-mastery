Chapter 1 — Code Examples

Example 1 — Hello World

The simplest possible Node.js script. Save as 01-hello.js and run with node 01-hello.js.

// 01-hello.js
console.log("Hello, World!");

Output:

Hello, World!

Example 2 — Using the process Object

Inspecting the current Node.js process and passing command-line arguments.

// 02-process.js
console.log("Node version :", process.version);
console.log("Platform     :", process.platform);
console.log("Architecture :", process.arch);
console.log("Working dir  :", process.cwd());
console.log("Script path  :", __filename);
console.log("Script dir   :", __dirname);

// Access command-line arguments
// Run: node 02-process.js Alice 42
const args = process.argv.slice(2); // skip "node" and script name
console.log("Arguments    :", args);

if (args.length) {
  console.log(`Hello, ${args[0]}! You passed ${args.length} argument(s).`);
}

Run:

node 02-process.js Alice 42

Output:

Node version : v22.11.0
Platform     : darwin
Architecture : arm64
Working dir  : /home/user/projects
Script path  : /home/user/projects/02-process.js
Script dir   : /home/user/projects
Arguments    : [ 'Alice', '42' ]
Hello, Alice! You passed 2 argument(s).

Example 3 — Reading Environment Variables

Access environment variables via process.env. Never hard-code secrets in source code — use env vars instead.

// 03-env.js
const port = process.env.PORT || 3000;
const env  = process.env.NODE_ENV || "development";

console.log(`Server will listen on port ${port} in ${env} mode.`);

Run (setting env vars inline):

# macOS / Linux
PORT=8080 NODE_ENV=production node 03-env.js

# Windows PowerShell
$env:PORT="8080"; $env:NODE_ENV="production"; node 03-env.js

Output:

Server will listen on port 8080 in production mode.

Example 4 — Timers

Node.js exposes the same timer functions as the browser.

// 04-timers.js

// Run once after 1 second
setTimeout(() => {
  console.log("setTimeout fired after 1 s");
}, 1000);

// Run every 500 ms, stop after 3 fires
let count = 0;
const id = setInterval(() => {
  count++;
  console.log(`setInterval tick #${count}`);
  if (count === 3) clearInterval(id);
}, 500);

console.log("Timers registered — waiting...");

Output:

Timers registered — waiting...
setInterval tick #1
setInterval tick #2
setInterval tick #3
setTimeout fired after 1 s

Example 5 — Simple HTTP Server

Node.js has a built-in http module — no framework needed for a basic server.

// 05-http-server.js
const http = require("http");

const server = http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "text/plain" });
  res.end(`Hello from Node.js!\nURL: ${req.url}\nMethod: ${req.method}\n`);
});

const PORT = process.env.PORT || 3000;
server.listen(PORT, "127.0.0.1", () => {
  console.log(`Server running at http://127.0.0.1:${PORT}/`);
});

Run:

node 05-http-server.js

Then open http://127.0.0.1:3000 in your browser, or:

curl http://127.0.0.1:3000/hello
