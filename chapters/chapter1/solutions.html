Chapter 1 — Solutions

Try each exercise yourself first. Reveal the solution only when you are stuck or want to compare approaches.

Solution 1 — System Info Reporter

Show solution 
// sysinfo.js
console.log("Node.js version  :", process.version);
console.log("Platform         :", process.platform);
console.log("Architecture     :", process.arch);
console.log("Working directory:", process.cwd());
console.log("Script path      :", __filename);

Key points:

  • process.version returns the Node.js version string (e.g. v22.11.0).
  • process.platform returns "linux", "darwin", or "win32".
  • __filename is a global available in every CommonJS module.

Solution 2 — Greeting with Command-Line Arguments

Show solution 
// greet.js
const args = process.argv.slice(2);

if (args.length < 2) {
  console.error("Usage: node greet.js  ");
  process.exit(1);
}

const name = args[0];
const age  = parseInt(args[1], 10);

if (isNaN(age)) {
  console.error("Error: age must be a number.");
  process.exit(1);
}

console.log(`Hello, ${name}! You are ${age} years old.`);
console.log(`In 5 years you will be ${age + 5}.`);

Key points:

  • process.argv.slice(2) strips the first two entries (node path and script path).
  • parseInt(value, 10) — always supply the radix to avoid octal parsing bugs.
  • process.exit(1) signals failure to the shell (non-zero exit code).

Solution 3 — Countdown Timer

Show solution 
// countdown.js
const n = parseInt(process.argv[2], 10) || 5;
let current = n;

const id = setInterval(() => {
  console.log(current);
  current--;
  if (current === 0) {
    clearInterval(id);
    console.log("Go!");
  }
}, 1000);

Key points:

  • setInterval fires the callback every 1000 ms.
  • clearInterval(id) stops the timer once the countdown reaches zero.
  • The || 5 default only kicks in if no argument or an invalid argument is given (parseInt returns NaN which is falsy).

Solution 4 — Minimal HTTP Server

Show solution 
// server.js
const http = require("http");

const PORT = process.env.PORT || 3000;

const server = http.createServer((req, res) => {
  console.log(`${req.method} ${req.url}`);

  if (req.method === "GET") {
    res.writeHead(200, { "Content-Type": "text/plain" });
    res.end("Node.js is running!\n");
  } else {
    res.writeHead(405, { "Content-Type": "text/plain" });
    res.end("Method Not Allowed\n");
  }
});

server.listen(PORT, "127.0.0.1", () => {
  console.log(`Listening on http://127.0.0.1:${PORT}`);
});

Key points:

  • Always bind to 127.0.0.1 (localhost) for local development — never 0.0.0.0.
  • req.method is always uppercase ("GET", "POST", etc.).
  • HTTP 405 is the correct status code for an unsupported HTTP method.
